
# Student Performance Prediction using Machine Learning

## Project Description
This project predicts student final marks using Machine Learning.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Random Forest Regression

## Dataset
UCI Student Performance Dataset

## Input Features
- Study Time
- Previous Failures
- Absences
- First Period Marks
- Second Period Marks
- Age

## Output
Predicted Final Student Marks.

## How to Run
1. Install Python.
2. Install required libraries.
3. Run student_prediction.py.
4. Enter student details.
5. View predicted marks.
